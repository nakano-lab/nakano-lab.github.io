Hashleaf
Support

Updated August 19, 2026

Hashleaf is a focused Markdown viewer for iPhone, iPad, and Mac. It displays images, headings, tables, code, math, and a table of contents, includes search and multiple documents, and provides separate windows and Finder Quick Look previews on Mac.

System requirements

  • iPhone and iPad: iOS or iPadOS 17 or later
  • Mac: macOS 14 or later
  • Markdown extensions: .md, .markdown, and .mdown
  • Text encodings: UTF-8, UTF-16, and Shift_JIS
  • Maximum Markdown file size: 10 MB

The interface automatically follows your device’s preferred languages. Hashleaf supports English, Japanese, Korean, Simplified and Traditional Chinese, Spanish, French, German, Brazilian Portuguese, and Italian.

Getting started

Open Markdown files

  1. On the welcome screen or in the menu, select Open Markdown Files.
  2. Choose one or more Markdown files in Files or Finder.
  3. Use the toolbar or menu for the table of contents, search, text size, and sharing.

Switch between multiple open documents from the menu. On Mac, documents opened from Finder appear in separate windows. If Apple’s document picker grants access only to the Markdown file, Hashleaf may ask you to select its folder before it can load relative images and linked local files.

Open a folder containing Markdown

  1. From the menu, select Open Folder Containing Markdown.
  2. Choose the folder containing the Markdown and referenced images.
  3. If the folder contains multiple Markdown files, select the document to display.

Files and folders can be opened from local storage, iCloud Drive, Dropbox, and other cloud storage providers that appear in Files or Finder.

Preview with Quick Look on Mac

  1. Launch Hashleaf once.
  2. Select a Markdown file in Finder.
  3. Press the Space bar.

Quick Look displays Markdown and rendered math. If macOS has not recognized the extension yet, quit and reopen Hashleaf and Finder.

Display images used in a document

When Markdown contains a relative reference such as ![Description](images/photo.png), select Open Folder Containing Markdown and choose the folder where the Markdown file is stored. After selecting the Markdown inside that folder, Hashleaf can read the images and linked files referenced by the document. This feature is available for free.

Folder selection is required by iOS, iPadOS, and macOS security. Hashleaf does not sign in directly to Dropbox, Google Drive, OneDrive, or another storage service. A provider works when it appears in Files or Finder through File Provider and can download the required files to the device.

Hashleaf remembers an authorized folder on the device and reuses access when possible. You may need to select it again if the operating system or cloud provider revokes access or if the files are moved.

Image limits are 32 MB per image and 128 MB per document on iPhone and iPad, and 64 MB per image and 256 MB per document on Mac. Supported formats are PNG, JPEG, GIF, WebP, HEIC/HEIF, TIFF, BMP, AVIF, and SVG.

Frequently asked questions

Images are not displayed

  • Use Open Folder Containing Markdown and select the folder containing the Markdown file.
  • Check that the relative path, capitalization, extension, and actual filename match.
  • For security, files outside the selected folder cannot be read. Keep the Markdown and its referenced files in the same folder hierarchy.
  • If a cloud file shows a cloud icon, confirm that Files or Finder can download it.
  • Check the supported formats and size limits above.

Math is still displayed with $$

Write inline math as $E = mc^2$. Put $$ before and after display math. Confirm that the opening and closing delimiters match and that the expression is not inside a code block. Math resources are bundled with Hashleaf and normally require no network connection.

How do I search a document?

Select Search. On Mac, you can also press Command-F. Free search covers the currently displayed document. With Hashleaf Pro, Folder Tools can search every Markdown file in a selected folder.

What happens when I select a link?

Within an authorized folder, Markdown files open in Hashleaf, while folders and other files are passed to the operating system and opened by a compatible default app. Web, email, and telephone links also open in the corresponding system app.

How do I export PDF or HTML?

With Hashleaf Pro, open a document and select Export Studio from the menu. Choose PDF or self-contained HTML. You can set a theme, custom CSS, PDF paper size, orientation, margins, header, footer, page numbers, and a table of contents. Multiple documents can be exported individually or combined.

How do I check for broken links?

With Hashleaf Pro, select a folder in Folder Tools and run Link Check. Hashleaf checks local files and images referenced by Markdown throughout that folder.

How do I follow changes from an external editor on Mac?

With Hashleaf Pro, turn on Live Preview in the menu. Hashleaf automatically refreshes the displayed Markdown when an external editor saves it.

Is Hashleaf Pro a subscription?

No. Hashleaf Pro is a one-time In-App Purchase. On an iPhone, iPad, or Mac using the same Apple Account, select Restore Purchases. Pricing and purchase processing are managed by the App Store.

The price will not load, or the purchase cannot be completed

  • Confirm that you are signed in to the App Store and connected to the internet.
  • Check Screen Time or managed-device restrictions for In-App Purchases.
  • Wait briefly, then select Reload Purchase Information or Restore Purchases.
  • If you already purchased Pro, use the same Apple Account that made the purchase.

If the issue continues, contact us with a screenshot that hides personal information and include the device, OS, and Hashleaf version and build.

Are my files sent to the developer?

No. Selected Markdown, relative images, linked files, and generated PDF or HTML files are processed on your device. If a Markdown document embeds an image from a web URL, however, your device contacts that web server to load the image. See the Privacy Policy for details.

Contact

When reporting a problem, do not include personal information or confidential document content. Please include the Hashleaf version and build; device and OS; storage location, such as On My Device, iCloud Drive, or Dropbox; steps leading to the issue; and any error shown. If possible, provide a non-confidential Markdown file that reproduces the problem.
