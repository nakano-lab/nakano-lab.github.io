Programming Dojo for MATLAB®
Support

Last updated: October 15, 2026 · Provider: Takashi Nakano

Find help with lessons, code practice in MATLAB® Mobile™, and advertising choices. App Store release is in preparation.

Requirements and languages

  • An iPad with iPadOS 17 or later. This is not an iPhone or Mac app.
  • Japanese and English interface and lessons. Japanese is used when it is first in your iPad's preferred language list; otherwise English is used.
  • Explanations, questions, search, references, and error help work offline.
  • No app account or in-app purchases.

Run code in the separately available MATLAB® Mobile™ app. MathWorks provides its account, licensing, and connection requirements.

Access for code practice

Code practice assumes access to MATLAB® Mobile™ or MATLAB® Online™. Full functionality requires a valid MATLAB license linked to your MathWorks account. Check MathWorks requirements, including eligible license types and current Software Maintenance Service. Limited free access is available without a license, with feature or usage limits. Lessons and knowledge checks work in this app alone. Device-sensor tasks require MATLAB® Mobile™.

Select “Don't show again” on the startup notice to hide it on later launches. Re-enable it with “Show the notice at startup” in Setup & Usage.

Getting started

  1. Choose a belt on Home, then open a lesson from the list.
  2. Read the explanations and examples in Stage 1: Learn.
  3. Answer the three questions in Stage 2: Reason, and read the feedback.
  4. Copy the code from Stage 3: Practice into MATLAB® Mobile™, run it, and inspect the results.
  5. Complete the practice checks and follow the self-certification criteria shown in the app.

There are 36 core lessons and one optional advanced lesson, Tilt to Land, totaling 37 lessons and 111 questions. The optional lesson is separate from core progress.

Using code and CSV files in MATLAB® Mobile™

Run the code

  1. Select Copy Code in the practice material.
  2. Open MATLAB® Mobile™ and paste it into the command area or a script, following the lesson instructions.
  3. If a training file or function is needed, save it with the specified name and folder.
  4. Compare the output with the lesson's checks.

Programming Dojo for MATLAB® does not execute MATLAB code. It has no API connection to MATLAB® Mobile™ and does not automatically receive execution results.

Save training files

Select Save Training File and choose a destination in Apple's standard file browser. If needed, move the file somewhere MATLAB® Mobile™ can access it. Check the current folder and file name. Storage and synchronization follow the settings of the service you choose.

Function exercises may require separate files for the function definition and calling code. Use the file name specified in the lesson and open its folder in MATLAB® Mobile™. See MathWorks documentation on files and folders.

Progress, records, and self-certification

Completion, quiz answers, practice checks, learning-stage drafts, self-certification, and the most recently opened lesson are stored on your iPad. There is no developer-operated account or cloud synchronization.

The app checks quiz answers, but it does not automatically grade MATLAB® Mobile™ execution results. Self-certification uses quiz feedback and practice checks you have verified yourself.

Use Setup & Usage > Reset All Training Records to delete local learning records. This cannot be undone, so check what you need before resetting. Manage separately exported CSV files at their destination.

Advertising and privacy

Banners appear only on Home and lesson lists. They are not placed during lessons, quizzes, practice, search, or reference reading. Region, consent, ad availability, and connectivity can affect whether an ad appears. Learning remains available without ads.

Change your choices

Open Ads & Privacy at the top of the app. Where Google UMP requires it, an option to change your privacy choices is shown. Ads may not be requested when the required consent is unavailable.

Report an inappropriate ad

Use AdChoices or the information controls in an ad, or open the reporting link in Ads & Privacy. Contact support below for display issues or ads that interfere with learning. You do not need to repeatedly click an ad to investigate it.

Non-personalized ads still involve advertising SDK data processing. See the privacy policy.

Frequently asked questions

Can I use the app without MATLAB® Mobile™?

Lessons, knowledge checks, search, references, and error help work in this app alone. Code practice uses MATLAB® Mobile™ or MATLAB® Online™.

Where does the lunar-landing game run?

Run the code you build in MATLAB® Mobile™. Programming Dojo for MATLAB® does not include a finished game you can play directly inside the app.

Why does Tilt to Land not respond live?

The task records Orientation data in MATLAB® Mobile™ and replays the recording as control input. It is not a live control. Check that the data is not empty, and follow the sensor-recording steps and lesson code.

Why is a file or function not found?

Check the current folder, file name and extension, function name, and pasted code in MATLAB® Mobile™. Prepare the CSV and function files specified in the lesson.

What if the app will not open or display correctly?

Check for available iPadOS and app updates, close the app, and restart your iPad. If the issue continues, contact us with the details below. You do not need to start by deleting the app or resetting all records, which could remove your learning history.

Can I practice in MATLAB® Online™?

MATLAB® Online™ can be used for ordinary code practice, although the instructions mainly describe MATLAB® Mobile™. Record device sensors with MATLAB® Mobile™. Check the MATLAB® Online™ access requirements.
