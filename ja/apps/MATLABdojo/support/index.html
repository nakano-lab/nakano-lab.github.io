MATLAB道場
サポート

更新日: 2026年10月9日 · 運営者: Takashi Nakano

教材の読み方、MATLAB Mobileでの実習、広告の設定についてご案内します。本アプリはApp Store公開準備中です。

動作環境と言語

  • iPadOS 17以降のiPad（iPhone・Mac用アプリではありません）
  • 画面と教材は日本語・英語。iPadの優先言語の先頭が日本語なら日本語、それ以外は英語です
  • 説明、問題、索引、巻物、エラーガイドはオフラインで利用できます
  • MATLAB道場の利用にアカウント登録やApp内課金はありません

コード実行は別のアプリ、MATLAB Mobileで行います。MATLAB Mobileの利用条件やライセンス、接続条件はMathWorksの案内をご確認ください。

学習の進め方

  1. ホームで帯を選び、修行一覧から取り組む修行を開きます。
  2. 一の型「学ぶ」で、考え方とコード例を読みます。
  3. 二の型「見抜く」で3問に回答し、結果と理由を確認します。
  4. 三の型「試す」でコードをコピーし、MATLAB Mobileで実行・検証します。
  5. 実習の確認項目をチェックし、画面に表示される基準に沿って自己認定します。

本編は36修行です。任意の発展課題「傾けて着陸」1修行を含めると合計37修行、111問になります。発展課題は本編の進捗集計とは別です。

コードとCSVをMATLAB Mobileで使う

コードを実行する

  1. MATLAB道場の実習で「コードをコピー」を押します。
  2. MATLAB Mobileを開き、課題の指示に従ってコマンド欄またはスクリプトへ貼り付けます。
  3. 教材ファイルや関数が必要な場合は、指定の名前・フォルダで保存します。
  4. 実行結果と、教材の確認項目を見比べます。

MATLAB道場内でMATLABコードは実行しません。両アプリの間にAPI連携はなく、結果を自動で受け取る機能もありません。

CSV教材を保存する

「教材ファイルを保存」を押し、Appleの「ファイル」画面で保存先を選びます。必要ならMATLAB Mobileから利用できる場所へ移し、現在のフォルダとファイル名を確認してください。保存先や同期の扱いは、選択したサービスの設定に従います。

関数の課題では、関数本体のファイルと呼び出し側のコードを分けます。教材で指定したファイル名にし、MATLAB Mobileでそのファイルがあるフォルダを開いてください。MathWorksのファイル・フォルダの説明も参照できます。

進捗、記録、自己認定

完了状況、問題の回答、実習チェック、学習段階の下書き、自己認定、直前に開いた修行は端末内に保存されます。独自のアカウントやクラウド同期はありません。

問題の回答はアプリ内で確認できますが、MATLAB Mobileの実行結果は自動採点しません。自己認定は、問題の結果と自分で確認した実習項目に基づきます。

「準備と使い方」の「すべての修行記録をリセット」で学習記録を削除できます。リセットは取り消せないため、必要な内容を確認してから実行してください。別途書き出したCSVは保存先で管理します。

広告とプライバシー

広告はホームと修行一覧のバナーだけです。解説、問題回答、実習、索引、巻物には配置しません。地域、同意、広告在庫、通信状態などで表示されないことがあります。広告が出なくても教材は利用できます。

同意を変更する

アプリ上部の「広告とプライバシー」を開きます。Google UMPが必要と判断する地域・状態では、プライバシーの選択を変更する項目が表示されます。必要な同意が得られていない場合、広告をリクエストしないことがあります。

不適切な広告を報告する

広告内のAdChoices・情報表示を確認するか、「広告とプライバシー」の広告報告リンクを使ってください。教材の操作を妨げる広告や表示上の不具合は、下記サポートにもご連絡ください。調査のために広告を繰り返しクリックする必要はありません。

非パーソナライズ広告でも広告SDKのデータ処理はあります。詳しくはプライバシーポリシーをご確認ください。

よくある質問

MATLAB Mobileを入れなくても使えますか？

教材、理解確認、検索、巻物、エラーガイドはMATLAB道場だけで利用できます。サンプルを実際に動かす実習ではMATLAB Mobileを使います。

月面着陸ゲームはどこで動かしますか？

教材の手順に従って作ったコードをMATLAB Mobileで実行します。MATLAB道場には、完成済みゲームを直接プレイする機能はありません。

「傾けて着陸」が反応しません

この課題は、MATLAB MobileでOrientationデータを記録し、その記録を再生して操縦する方式です。リアルタイム操作ではありません。取得したデータが空でないこと、センサーの記録手順、課題内のコードを確認してください。

ファイルが見つからない、関数を呼べないと表示されます

MATLAB Mobileで現在のフォルダ、ファイル名と拡張子、関数名、貼り付けたコードを確認します。必要なCSV・関数ファイルを、教材の指定どおりに用意してください。

起動や表示に問題があります

利用可能なiPadOSとアプリの更新を確認し、アプリを終了してiPadを再起動してください。改善しない場合は、以下の情報を添えてお問い合わせください。記録が失われる可能性があるため、アプリ削除や全記録リセットを最初の対応として行う必要はありません。

Support in English

Requires an iPad with iPadOS 17 or later. The interface and lessons are Japanese or English, based on the first preferred iPad language. MATLAB Dojo has no app account or in-app purchases. App Store release is in preparation.

Getting started

  1. Choose a belt and lesson from Home.
  2. Read Stage 1 (Learn).
  3. Answer the three Stage 2 (Reason) questions and read the feedback.
  4. Copy the Stage 3 (Practice) code into the separately available MATLAB Mobile app.
  5. Run and inspect the results, complete the practice checklist, and follow the self-certification criteria.

There are 36 core lessons and one optional advanced lesson, totaling 111 questions. MATLAB Dojo does not execute MATLAB code or automatically grade its results. The lunar-landing game runs in MATLAB Mobile. Tilt to Land records orientation there and replays the logs; it is not live motion control inside MATLAB Dojo.

Code and CSV files

Use Copy Code and Save Training File. Choose a destination in Apple's standard file browser, then make the file available to MATLAB Mobile. Check the current folder, file name, function name, and extension. Function definitions and calling code may need separate files. MATLAB Mobile may require a MathWorks account, an eligible license, and a network connection.

Learning records

Completion, answers, practice checks, drafts, self-certification, and the most recently opened lesson are stored on your iPad. There is no developer-operated account or cloud synchronization. Setup & Usage > Reset All Training Records deletes local records; this cannot be undone. Manage separately exported CSV files at their destination.

Advertising and choices

Non-personalized banners are limited to Home and lesson lists. No banners are placed during lessons, quizzes, practice, search, or reference reading. Learning works if ads cannot be loaded. Open Ads & Privacy to change choices when required by Google UMP, review the policies, or report an inappropriate ad. AdChoices or an ad's information controls can also provide reporting options. See our privacy policy.
