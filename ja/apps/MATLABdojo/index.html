Nakano Lab Software / MATLAB道場

MATLAB道場

学んで、見抜いて、コードで試す。

iPad専用日本語・英語36＋1修行 · 111問広告あり

変数や配列の基礎から、データの可視化、数値シミュレーションへ。説明を読み、コードの結果を考え、MATLAB Mobileで実際に試す。白帯から黒帯まで、ひとつずつ理解を積み上げる学習アプリです。

Learn · Reason · Practice

読むだけで終わらない、
三つの型。

各修行を三段階で進めます。問題の回答と実習チェックは端末内に保存され、途中から再開できます。

一

学ぶ

考え方と書き方を、具体例や比較表で理解。行列演算と要素演算など、混同しやすい点を見比べます。

二

見抜く

コードの結果を予想し、各修行の3問で理解を確認。正解だけでなく、その理由を読みます。

三

試す

サンプルをMATLAB Mobileへコピーして実行。観察・検証項目をチェックし、自分で達成状況を確認します。

Four belts

基礎から、月面着陸へ。

本編は36修行。任意の発展1修行を含め、合計37修行と111問を収録しています。ホームの進捗は本編36修行を対象に表示します。

白帯 · 本編4修行

計算とデータの第一歩

基礎計算、変数、配列、条件分岐を学び、短いコードで結果を確かめます。

青帯 · 本編12修行

コードを組み立てる

スクリプト、繰り返し、関数などを使い、繰り返せる処理や再利用できるコードへ進みます。

茶帯 · 本編10修行

データを読み、伝える

ファイル、table、可視化、記述統計を学習。同梱の5種類のCSV教材で実習できます。

黒帯 · 本編10修行＋任意の発展1修行

月面着陸ゲームを作る

高度・速度・燃料をモデル化し、数値シミュレーション、操縦、飛行記録、着陸判定、自動操縦を段階的に組み立てます。

Optional advanced challenge

発展課題「傾けて着陸」

MATLAB Mobileで端末の向きのデータを記録し、その記録を再生して着陸の操縦に使います。センサーデータの取得、可視化、入力への変換を学ぶ任意の課題です。

リアルタイムの傾き操作をMATLAB道場内で実行する機能ではありません。コード実行とセンサー記録はMATLAB Mobileで行います。

理解と検証を重視

問題の回答結果と実習の確認項目で達成状況を確認します。MATLABの実行結果を自動採点する機能はありません。

In the app

実際の教材画面。

日本語のiPad画面です。画像を押すと拡大できます。月面着陸の画像はゲームを作るための教材で、ゲーム実行画面ではありません。

Tools for learning

つまずいたときの道具も。

01

索引と横断検索

修行本文、コード、関数、記号、エラーを検索。気になる言葉から教材へ戻れます。

02

巻物とエラー道場

関数・記号の参考資料とエラーガイドを確認。参考資料は別ウインドウでも開けます。

03

CSV教材と記録

5種類のCSVを「ファイル」へ保存。回答、実習チェック、自己認定などの記録は端末内に保存します。

Requirements & privacy

始める前に。

iPadとMATLAB Mobile

iPadOS 17以降のiPadに対応。画面と教材は日本語・英語です。教材閲覧はMATLAB道場だけで利用でき、コード実行には別途MATLAB Mobileを使います。MATLAB MobileではMathWorksアカウント、利用可能なライセンス、ネットワーク接続が必要になる場合があります。

広告とデータの取り扱い

オンライン時はホームと修行一覧に非パーソナライズのバナー広告が表示される場合があります。解説・問題回答・実習には広告を配置しません。広告が取得できない場合も教材は使えます。学習記録を広告サービスへ渡しませんが、広告SDKによるデータ処理はあります。詳しくはプライバシーポリシーをご確認ください。

English summary

MATLAB Dojo

Learn programming and data analysis step by step on iPad. The course includes 36 core lessons, one optional advanced lesson, 111 knowledge-check questions, and five CSV training files.

Each lesson follows Learn, Reason, and Practice. Build your skills from calculations, arrays, loops, and functions to files, tables, visualization, statistics, and a lunar-landing game. The optional Tilt to Land task records orientation in MATLAB Mobile and replays those logs for control.

MATLAB Dojo does not execute MATLAB code or automatically grade MATLAB execution results. Copy examples to the separately available MATLAB Mobile app to run them. MATLAB Mobile may require a MathWorks account, an eligible license, and a network connection.

Requires iPadOS 17 or later. The interface and lessons are in Japanese and English: Japanese is used when it is first in the iPad's preferred language list; otherwise English is used. Lessons, quizzes, search, references, and error help work offline. Learning records are stored on the device.

Non-personalized banners may appear on Home and lesson lists when online, not during lessons, quizzes, or practice. Advertising SDKs still process data; see the privacy policy. Learning features remain available without ads. There are no in-app purchases. App Store release is in preparation.
