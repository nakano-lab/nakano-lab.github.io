Nakano Lab Software / CODO Monitor

Real-time HRV analysis

CODO
Monitor

ECG信号から時間領域・周波数領域の心拍変動（HRV）指標をリアルタイムに計算し、短期と長期の変化を可視化するモニタリングソフトウェアです。

Main features

変化をリアルタイムに捉え、あとから振り返る。

01

HRV指標をリアルタイム計算

時間領域と周波数領域の複数指標を計算し、同時に可視化します。

02

個人化された適応アラート

蓄積されたデータに基づく閾値で外れ値を検出し、変化を強調します。

03

短期・長期を同時監視

直近の変化と長時間のトレンドを見比べ、状態の把握を支援します。

04

アーチファクトを除外

ケアや処置の区間を記録し、個人化閾値の計算から除外できます。

05

イベント注釈とメモ

投薬、処置などのイベントを時刻とともに記録し、レビューに役立てます。

06

ログと図を保存

解析値、時刻、アラート、注釈を記録し、データと図を出力できます。

重要

CODO Monitorはソフトウェアによる解析・可視化を支援するツールです。医療判断や診断を代替するものではありません。施設の運用基準、倫理、情報管理規程に従って使用してください。
